# mcp-telegram — fork progress

This is a fork of github.com/Prgebish/mcp-telegram with additional features
focused on safety, observability and operational robustness.

## Status

- Forked: 2026-05-12
- Upstream: github.com/Prgebish/mcp-telegram (MIT)
- Fork:     github.com/brendonlee20042004-sys/mcp-telegram

Upstream baseline:
- Go 1.26 + gotd/td + official MCP Go SDK
- 8 tools: tg_me, tg_dialogs, tg_history, tg_search,
           tg_send, tg_forward, tg_draft, tg_mark_read
- Default-deny ACL (per-chat permissions: read, send, draft, mark_read)
- Token bucket rate-limiter on every MTProto RPC
- Symlink-aware filesystem boundary for upload/download
- Lazy peer resolution (no FLOOD_WAIT at startup)
- Session file 0600
- ~4300 LoC, full test coverage on every package

## Roadmap (priorities)

### High priority (production blockers)
- [x] Reconnect logic on Telegram disconnect       (PR #8, merged)
- [ ] Approval middleware for destructive tools (send/forward/file upload)
- [x] Audit log of every tool invocation           (PR #3, merged)
- [x] Health-check tool (tg_health)                (PR #4, merged)

### Medium priority (UX & safety)
- [ ] QR-code login flow (alternative to phone+SMS)
- [ ] Content scanner: flag prompt-injection / hidden unicode in incoming
      messages, mark output as untrusted via _meta annotations
- [ ] Output annotations (_meta.from_user_data, trust_level, scan_findings)
- [x] Regex matchers in ACL (@news_*, regex:...)   (PR #5, merged)
- [x] Inverse ACL rules (explicit deny)            (PR #6, merged)
- [x] Dry-run flag for write tools                 (PR #7, merged)
- [ ] Per-chat send rate limit (already global, add per-peer)

### Low priority (nice to have)
- [ ] Local SQLite cache + FTS5 for offline history search
- [ ] Capability tokens with TTL for high-risk chats (boss, finance)
- [ ] Multi-account support (account: <name> in config + ACL rules)
- [ ] Per-account proxy (SOCKS5, MTProxy)
- [ ] Stories / reactions / channel analytics tools
- [x] tg_get_message (single message by ID)
- [ ] tg_get_replies (thread replies)
- [ ] tg_extract_links (mentions, urls, emails from posts)
- [ ] tg_discover_related_channels (analyze forwards)
